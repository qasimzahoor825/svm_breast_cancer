# 🧠 Breast Cancer Classification using SVM

This project applies **Support Vector Machine (SVM)** on the Breast Cancer dataset from scikit-learn.

## 🚀 Features
- Loads the breast cancer dataset
- Uses only the first two features for visualization
- Splits dataset into training (70%) and testing (30%)
- Trains an SVM classifier (RBF kernel)
- Evaluates performance with:
  - Confusion matrix
  - Classification report
- Visualizes confusion matrix with heatmap

## 📊 Output
- Confusion Matrix (model predictions vs actual)
- Classification report (precision, recall, F1-score, accuracy)

## 🛠️ Tech Stack
- Python
- scikit-learn
- NumPy
- Matplotlib
- Seaborn
